# NekoDrift

A pixel cat that lives on your desktop. Follows your cursor, reacts to typing, integrates with Claude Code.

---

## Quick start

Download from [Releases](https://github.com/SumitKumar-17/nekodrift/releases) — the **Nightly** build is updated automatically on every push.

Or build from source:

```bash
npm install && npm run build && npm start
```

## Features

- Cursor follow with smooth lag and eye tracking
- Typing detection — WPM drives heat level and animations
- Idle detection, scroll reaction, cursor shake wobble
- Drag to reposition (Mochi drag)
- Pomodoro timer and stretch reminders
- Daily scheduled reminder
- Pixel coat editor (16×16 grid, 10 colors)
- Mood system (happy / content / tired / lonely)
- Sound engine — purr, meow, chime (Web Audio, no files)
- Claude Code integration — cat reacts to every tool call
